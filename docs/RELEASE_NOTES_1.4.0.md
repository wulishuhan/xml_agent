# XML Agent 1.4.0 发布说明

这一版的主题是**双协议并行**：XML 与 JSON 两套动作协议同时可用，默认 XML，可在设置界面切换。
同时带来微信 / 浏览器两个新插件、会话级提示词变体（降低文本指纹）、ChatGPT 2026 版适配，
以及一批真机验证过的稳定性修复。

协议切换不影响既有任务：默认 XML 是新的首轮提示词，JSON 通道完整保留，任选其一即可。
`apiVersion` 仍为 `1`，插件 / 技能契约无破坏性变更。

## 一、双协议并行（核心）

1.3.0 及之前只有 JSON 协议（`{"action":"read","params":{...}}`）。1.4.0 起两套协议并存：

| 协议 | 动作写法 | 默认 | 提示词 |
| ---- | -------- | ---- | ------ |
| XML  | `<read path="..."/>` | ✅ 是 | 半文半白，约 1440 字符 |
| JSON | `{"action":"read","params":{"path":"..."}}` | 否 | 完整 JSON Schema，约 4270 字符 |

- **统一执行层**：两套协议只对输入解析和提示词不同，执行层共用同一套 actions / runtime / ajv schema。XML 解析后归一化为 `{action, params}` 信封，零改动复用执行链路。
- **切换方式**：设置界面 Agent 页的 XML/JSON 分段按钮（中英文文案），保存后新任务生效；CLI 用 `--protocol`，配置用 `agent.protocol`（env `AGENT_ACTION_PROTOCOL`）。
- **提示词分文件夹**：`prompts/xml/` 与 `prompts/json/` 各存一套，`prompts/protocol.js` 按协议路由首轮 / 错误 / 回贴 / 收尾 / 发送失败等全部提示词。顶层 `prompts/*.js` 保留 JSON 版以兼容既有指纹测试。

### 插件与技能的协议兼容

这次同时修掉了双向串协议的问题：

- 插件用法示例按协议渲染：XML 下折算成标签（`fetch` → `<fetch url="..." method="GET"/>`），JSON 下保留 `{action, params}` 结构；`screenshot` 这类复杂参数用新增的 `usageXml` / `usageJson` 显式声明，老插件写了异协议示例时降级为文字说明，不把模型带偏。
- 技能文档去掉裸 XML 示例，技能段明确"动作语法按本会话首条消息协议，技能文档只讲做事方法"。
- 新增 6 条双向串协议守卫断言，`test-dual-protocol` 共 34/34。

## 二、插件：微信与浏览器操作

- **微信桌面端操作插件**（Windows，键鼠 + OCR 黑盒方案）：动作互斥闸门、返回语义与判重已修复。
- **浏览器操作插件**（CDP 白盒方案）：截图改用运行期 `ctx`，`ensurePage` 加单飞防重入。
- 插件动作识别改为从注册表派生；Qwen 发送链路补了两处"假装成功"的漏检。
- WebUI 插件卡片支持折叠，收起时显示摘要行。

## 三、提示词与反检测

- 首提示词与每轮回贴引入**会话级变体池**：一场会话抽一次、全程一致，会话之间文本不同，降低文本指纹；新增变体映射命中自检，防止正文改动导致变体静默退化。
- 提示词半文半白瘦身（首条约 −40%），默认收敛非核心插件与技能（现在插件默认全关、技能不自动装）。
- 补发 / 错误类提示词去掉宿主术语与原始栈信息，改口语变体，避免固定文本触发检测。

## 四、平台适配与稳定性

- **ChatGPT**：跟进 2026 版网页端 DOM，长提示词改用键盘输入；新任务复用失声会话会自动开全新会话；发送未生效时不再空等超时，改为逐级降级并以"输入框清空"验收。
- **GLM**：修复回复提取抓到用户消息与 CSS 样式噪声。
- **Gemini**：合并可运行版本，并支持 `BROWSER_PROXY` 环境变量让自启动浏览器走代理。
- **会话 / 进程**：WebUI 并发闸门异常隔离与排队会话重复启动防护；`killTreeSync` 改以进程存活为判据，放宽 taskkill 超时。
- **技能**：统一路径大小写口径，修复同步覆盖静默失效与测试状态依赖；结构化保存保留原 frontmatter 字段，正文拆分不再丢后半段。

## 五、验证

- `npm run test:offline` 全绿（EXIT=0）；双协议单测 34/34；插件 / 技能 / 提示词相关测试全过。
- Qwen 真机端到端（Edge CDP 9333）多轮全部 `completed` / 0 parse_error、retry、empty、send_error：
  - 核心动作闭环：`read → write → exec → answer → done`；
  - 插件 + 技能同时触发：读技能 → `fetch` 插件发真实 HTTP 请求 → answer → done；
  - 内置男频网文写作技能：读全文 → 按规范写 `outline.md`（卖点 / 金手指 / 爽点循环）→ answer → done。
  - XML 与 JSON 两轮均通过，动作语法无串协议。

## 六、升级说明

- 直接替换安装包即可，配置与工作区数据结构无变更。
- 默认协议变为 XML。若你的自动化脚本依赖旧 JSON 输出，请在设置界面切回 JSON，或使用 `--protocol=json` / `AGENT_ACTION_PROTOCOL=json`。
- 插件默认全部关闭，需要在 Plugins 面板按需启用；技能默认不自动安装，需要在 Skills 面板安装到工作区后模型才能读到。
